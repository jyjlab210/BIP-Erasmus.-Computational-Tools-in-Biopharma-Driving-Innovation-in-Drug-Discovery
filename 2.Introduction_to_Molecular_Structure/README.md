# 2. Introduction to Molecular Structure

This module combines molecular structure theory with practical exercises on acetylcholine-binding proteins (AChBPs), small-molecule modelling and construction of a neuronal membrane containing the human α4β2 nicotinic acetylcholine receptor (nAChR).

## Learning objectives

- Visualize protein assemblies and ligand-binding sites.
- Compare experimental, ideal and SMILES-derived ligand conformations and inspect protonation states.
- Prepare a membrane–protein model.

## Required software and online resources

| Tool | Purpose | Access / download |
| --- | --- | --- |
| PyMOL | Molecular visualization, editing and Builder | [Official installers](https://pymol.org/installers/) |
| RCSB PDB | Experimental coordinates and ligand chemical descriptors | [Protein Data Bank](https://www.rcsb.org/) |
| CORINA Classic | Generate 3D ligand structures from SMILES | [Online demo](https://demos.mn-am.com/corina_interactive.html) |
| CHARMM-GUI | Construct a neuronal membrane model | [Web server](https://www.charmm-gui.org/) |
| PLIP (optional) | Explore protein–ligand interactions | [Web server](https://plip-tool.biotec.tu-dresden.de/plip-web/plip/index) |

PyMOL is a desktop application; the other resources can be accessed in a browser. Check the PyMOL licence and operating-system requirements before installing.

## Getting started

Install PyMOL, then follow the [small-molecule construction guide](Practical_guides/Small_molecule_construction_PyMOL.pdf). For the membrane exercise, follow the [CHARMM-GUI tutorial](Practical_guides/CHARMM-GUI_neuronal_membrane_construction.pdf) using PDB entry [6CNK](https://www.rcsb.org/structure/6CNK). The practical focuses on building and inspecting the model; a molecular dynamics engine is not required.
