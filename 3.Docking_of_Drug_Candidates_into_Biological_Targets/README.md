# 3. Docking of Drug Candidates into Biological Targets

This module introduces ligand–target docking and a hands-on docking workflow involving six AChBP–ligand complexes.

## Learning objectives

- Prepare and superimpose receptor structures and separate their ligands.
- Define a docking search space and run receptor–ligand docking with AutoDock Vina.
- Inspect predicted poses and compare them with experimentally observed poses.

## Required software and online resources

| Tool | Purpose | Access / download |
| --- | --- | --- |
| PyMOL | Prepare and visualize structures and sessions | [Official installers](https://pymol.org/installers/) |
| DockingPie | PyMOL plugin for docking setup and analysis | [Download and installation](https://github.com/paiardin/DockingPie) |
| AutoDock Vina | Docking engine used in the practical | [Official website](https://vina.scripps.edu/) |
| RCSB PDB | Experimental protein–ligand structures | [Protein Data Bank](https://www.rcsb.org/) |

Install PyMOL first, then DockingPie using the PyMOL Plugin Manager. Follow the plugin's configuration instructions to install or configure Vina and its dependencies. Check compatibility and licensing for your operating system; open-source PyMOL may require manual dependency installation.
